# Functional Requirements
## Core
- Homepage with clear access points
- View a directory (buildings, facilities, etc)
- Detail view of locations

## Study Space Feature
- Search/filter
- Availability info
- Select rooms and time slots
- Confirmation of booking

## Content Management
- Admin should be able to add/edit/update locations

## Accessibility
- Wellbeing resources within MVP scope

# Non-Functional Requirements
## Usability
- Mobile responsive
- User should be able to complete core tasks within 3-4 clicks/taps
- Nav must be consistent across pages

## Design
- Minimalist UI design
- WCAG 2.2 standards

## Performance and reliability
- Speed (fast load)
- Graceful error handling
